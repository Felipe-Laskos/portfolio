# Portfólio - Felipe Laskos

Portfólio pessoal, bilíngue (PT/EN), hospedado em https://felipe-laskos.vercel.app

## Stack (v2)

- **Next.js 15** (Pages Router) + React 18
- **Tailwind CSS v4** - tema dark customizado via `@theme` em `styles/globals.css`
- **Motion** - animações de entrada e scroll-reveal
- **next-i18next** - internacionalização PT/EN (`public/locales/`)
- **react-icons** - ícones de marca (Simple Icons) e UI (Lucide)
- Fontes via `next/font`: Space Grotesk (títulos), Inter (texto), JetBrains Mono (detalhes)

## Rodando

```bash
npm install
npm run dev
```
